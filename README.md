## About

**RetroBug** is an open-source compatibility layer designed to run legacy 32-bit (`armeabi-v7a`) Android applications and games on modern 64-bit hardware. As newer operating systems and processors drop native 32-bit execution, RetroBug bridges the gap to keep legacy software functional.

## Features

* **ARMv7 Compatibility:** Runs legacy `armeabi-v7a` Android binaries seamlessly.
* **Dynamic Translation:** High-performance ARMv7 → ARM64 dynamic binary translation.
* **Per-App Profiles:** Custom compatibility profiles tailored for specific games and apps.
* **Advanced Environments:** Isolated, per-app environment configurations to prevent conflicts.
* **App Revival Patches:** Built-in compatibility patches to fix broken or abandoned applications.
* **Cross-Platform Target:** Designed for both Android and iOS environments.

## Status

> [!WARNING]  
> **RetroBug is currently in early development.**  
> Application compatibility varies heavily. Expect bugs, unfinished features, and breaking changes as development progresses.
